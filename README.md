# 最近聊天按角色分组 (Recent Chats Group)

SillyTavern 扩展：把欢迎页「最近的聊天」里散着按时间排列的所有存档，按角色合并成可展开的档案文件夹。一个角色 = 一个文件夹，点击文件夹展开该角色的全部聊天存档。

## 功能

- **按角色合并**：「最近的聊天」主页面中，同一角色的所有存档自动归到同一个档案文件夹下
- **点击展开**：点文件夹头（头像 + 角色名 + 存档数）展开/收起该角色的全部存档
- **无需点「显示更多」**：分组后不再隐藏靠后的存档，展开文件夹即可看到该角色的全部存档
- **群聊独立**：群聊存档统一归入「群聊」文件夹
- **原有功能全保留**：存档行的 打开 / 置顶 / 重命名 / 删除 全部照常工作
- **置顶可见**：含置顶存档的角色文件夹默认展开，置顶操作后能直接看到结果
- **状态记忆**：会话内记住你手动展开/收起的文件夹，刷新列表后保持
- **头像跟随**：文件夹头像显示角色真实头像（兼容柏宝箱等懒加载头像扩展）
- **主题跟随**：文件夹配色跟随酒馆主题，强制实色、无毛玻璃、文字对比度兜底
- **轻量化**：仅监听欢迎面板渲染（MutationObserver 直接子节点），无轮询、无动画开销

## 安装

1. 将整个 `recent-chats-group` 文件夹放到扩展目录：
   ```
   SillyTavern/data/default-user/extensions/recent-chats-group/
   ```
2. 刷新 SillyTavern 页面
3. 打开「最近的聊天」欢迎页即可看到按角色分组的档案文件夹

## 使用

1. 打开 SillyTavern 欢迎页（无活跃聊天时显示）
2. 「最近的聊天」列表自动按角色分组：每个角色一个文件夹头
3. 点击文件夹头展开该角色的全部聊天存档；再点一次收起
4. 存档行的点击打开、置顶、重命名、删除等操作与原来完全一致

## 文件结构

```
recent-chats-group/
├── manifest.json    # 扩展元数据
├── index.js         # 分组逻辑（监听欢迎面板渲染并重组 DOM）
├── index.css        # 分组样式（跟随主题变量，实色无毛玻璃）
└── README.md        # 本文件
```

## 实现说明

- 欢迎面板每次重建（刷新/置顶/删除/重命名后）都会重新渲染，扩展通过 MutationObserver
  捕获新渲染的 `.welcomePanel`，把平铺的 `.recentChat` 按 `data-avatar` 分组重排
- 存档行元素本身被移入分组容器，酒馆绑定在行上的点击/置顶/重命名/删除事件保持有效
- 分组头配色由 JS 实时读取主题 CSS 变量合成为不透明实色，只模仿主题配色

## 注意事项

- 只影响欢迎页「最近的聊天」的展示方式，不修改任何存档文件
- 展开状态仅保存在当前会话中，刷新页面后恢复默认（置顶组除外）
- 若同时安装了「聊天存档管理器」（设置面板版），两者互不冲突，可只保留其一
